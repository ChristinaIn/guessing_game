# Игра «Угадайка» <img width="25" height="25" alt="image" src="https://github.com/user-attachments/assets/3507e0fe-f805-4ce0-afe9-fab2fadc33a9" />

---

Это небольшая игра на угадывание слов.
Игрок выбирает тематическую область, после чего программа случайным образом загадывает слово. Задача игрока -
угадать слово по буквам или попробовать назвать его целиком.</p>

---

<p>Для разработки игры использовала язык программирования Python, дополнительно устанавливала пакеты:</p>
<div>
  <ul>
    <li><i>pyinstaller</i> для превращения Python-скрипта в самостоятельный файл .exe</li>
    <li><i>tkinter</i> для создания GUI игры</li>
  </ul>
</div>
